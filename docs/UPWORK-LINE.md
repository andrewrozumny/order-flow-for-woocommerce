## (a) Profile line

Built Order Flow for WooCommerce, a free plugin for custom order statuses, role-based transition rules, status emails and PDF documents.

## (b) Message to a client

Custom order statuses, transitions and PDF documents: I shipped exactly that in my Order Flow plugin. It adds your own statuses, controls which roles can move an order where, keeps a history of every change, and sends an email and a PDF at each step. I can set it up for your store or extend it for your process.
